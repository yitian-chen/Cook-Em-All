# 《锅里见》最终实现效果总结

> 一款「怪物即食材、Build 即菜谱」的料理主题 Survivors-like 可玩 Demo（PC，Unity 2D 俯视角）
> 本文档中的厨具、食材、怪物示例仅用作示例，实际应按照后续的具体设计文档。

---

## 1. 游戏流程（10 波次制）

```
第 1 波战斗 → 通关结算（获得金币）→ 商店（购买装备 / 扩容格子）→ 第 2 波 → … → 第 9 波 → 第 10 波 BOSS 战 → 通关
```

**每波独立**：每波有独立的刷怪配置与通关条件；**每波开始时角色回满血**（商店不卖回复补给）。

| 波次 | 类型 | 内容 | 通关条件 |
|---|---|---|---|
| 1–2 | 教学 / 低压 | 基础食材怪（辣椒怪、蘑菇怪） | 存活至消灭敌潮（固定数量的敌人） |
| 3–5 | 成长 | 敌潮递增 + 精英食材怪登场 | 存活至消灭敌潮 |
| 6–9 | 高压 | 高密度敌潮 + 多精英轮番 | 存活至消灭敌潮 |
| 10 | **BOSS 波** | 饕餮锅王 + 召唤小怪 | 击杀 BOSS |

**波次难度递增**：怪物体积/血量/速度提升、敌潮密度上升、精英出现更早、掉落稀有度提升。怪物掉落金币按波次递增。每次通过波次后回满玩家血量。
---

## 2. 游戏循环（核心闭环）

```
波次战斗
  → 击杀怪物，拾取金币
    → 商店花费金币购买厨具 / 食材 放入背包「挂点」激活菜品；购买格子（可能有1*1，1*2，1*3，2*2的格子，价格不同）扩容背包
      → 食材可带来增益，放在厨具的判定格中还可改变厨具攻击方式
        → 输出更强 → 通关 → 金币结算 → 商店（买装备 / 扩容背包）→ 下一波（难度+）
```

---

## 3. 背包与商店

### 3.1 背包（挂点判定格制）

| 功能 | 说明                                                           |
|---|--------------------------------------------------------------|
| 初始尺寸 | 4 × 3                                                   |
| 扩容 | 商店购买扩容（+行 / +列），**最大 5 × 7（35 格）**                           |
| 移动 / 旋转 | 物品可**随意移动**，可**旋转 90°**（如 2×1 厨具横放 / 竖放）                     |
| 激活机制 | 每件厨具在**周围挂有判定格（每种厨具判定格可能不同）**，把对应食材 / 技法放入挂点即**激活菜品、改变攻击方式** |
| 格位耦合 | 相邻物品菜系相合 → 持续数值增益（如川系+辣椒 → 伤害+20%、CD-10%），保留                 |

**厨具挂点布局示例（每厨具自定义）**

| 厨具 | 周围挂点  | 激活示例 |
|---|-------|---|
| 平底锅 | 食材×2  | 辣椒＋爆炒 → 火焰颠锅 |
| 菜刀 | 食材×2  | 牛肉＋切配 → 剁碎连斩 |
| 汤锅 | 食材×2  | 蘑菇＋炖煮 → 浓汤领域 |


### 3.2 商店（局内「流动菜市」）

| 功能 | 说明 | 花费 |
|---|---|---|
| 商品栏（6 个栏位） | 随机出售：食材 / 厨具 / 格子| 金币 |
| 刷新货架 | 重新随机上架装备栏 | 金币 |
| 锁定商品 | 下一波结束后该栏位商品不会刷新 |
| 合成服务 | 集齐对应装备可以合成更高级的装备（第一期暂时不做） |

商店不卖血量——**每波开始自动回满血**。

商店在每波通关结算后出现；金币由本波击杀掉落。

## 5. 关卡设计（10 波独立）

| 波次 | 模式 | 参数 | 奖励金币（参考） |
|---|---|---|---|
| 1–2 | 固定时间 | 90s / 90s | 50 / 80 |
| 3–5 | 固定时间 | 120s ×3 | 120 / 160 / 200 |
| 6–9 | 固定时间 | 120s ×4 | 260 / 320 / 380 / 400 |
| 10 | BOSS 战 | 击杀饕餮锅王 | 1000 |

- 每波**独立结算**：通关得金币 → 进商店 → 下一波；中途失败所有装备全部丢失，只能从第一波重新开始。
- 波次间隔的商店是**永久养成与临时强化的交汇点**：买装备直接上阵，买格子扩容拓展长期空间。

## 7. 其他装备（种类与格子大小）

| 类型 | 数量 | 格子大小 | 说明 |
|---|---|---|---|
| 食材 | 30 种 | 1×1 | 六元素系：火/冰/水菌/肉/面点/甜；决定攻击元素与附加状态 |
| 工具 | 7 种 | 1×1 | 永久合成材料：铲子/磨刀石/汤碗/冰桶/火钳/蒸架/菜板 |
| 成品菜 | 10 种 | 1×1 | 合成产物，可直接出战：水饺/蛋炒饭/面条/寿司/豆花… |
| 半成品 | 1 种 | 1×1 | 饺子（面团+肉末），再合成水饺 |
| 进阶厨具 | 8 种 | 1×1 / 2×1 / 2×2 | 见 6.2 |

**格子与摆放规则**：基础物品 1×1 或 2*1；大型厨具 1*3 / 2*3, 后续单独出设计文档。背包内物品可随意移动、旋转；**厨具的挂点判定随其实际摆放方向生效**（旋转后挂点方位跟随旋转）。

## 8. 一页验收

- 启动到进入战斗 ≤ 2 次操作
- 第 1 波 只有初始厨具。
- 菜品激活后攻击范围/颜色/节奏肉眼可见变化 + 菜名提示
- 10 波完整流程，第 10 波出现 BOSS 饕餮锅王；失败可从当前波重开
- 商店可购买装备和背包格子；每波开始回满血
- 连续 3 局无阻塞性报错、背包可移动/旋转/放置、菜品状态同步
