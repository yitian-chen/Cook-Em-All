# 美术资产需求清单

> 本文档根据《锅里见_装备与怪物设计.md》v4 MVP 版细化，列出每个具体美术文件的需求。
> 数值/名称若策划后续调整，本清单同步更新。

## 通用约定

- **格式**：PNG（带透明通道）；背景可用 PNG 或 JPG
- **分辨率**：PC 端 1920×1080，美术按 1x 制作
- **sprite sheet**：等间距横向排列，帧数固定；Unity 导入时配 `spriteMode: 2`(Multiple)、`spritePixelsToUnits`、`alignment: 7`(下中对齐)
- **单帧 sprite**：`spriteMode: 1`(Single)
- **命名**：全小写下划线分隔，避免中文与空格；格式 `类别_名称_用途.扩展名`
- **Alpha**：透明背景需干净，无黑边

- sprite sheet 需保持**等间距横向排列**，帧数与本文档一致
- 透明背景需 Alpha 通道干净，无黑边
- 命名全部小写下划线分隔，与本文档文件名一致
- 交付时附清单核对表，标记已完成/待补
