# 美术资产需求清单

> 本文档列出《锅里见》所需的美术资产类别、格式与分辨率要求。
> 具体种类、数量、数值待策划给出，此处仅给出**示例与规格约束**。

## 通用约定

- **格式**：角色/敌人/道具用 PNG（带透明通道）；UI 图标用 PNG；背景用 PNG 或 JPG
- **像素密度**：PC 端为主，目标分辨率 1920×1080，美术按 1x 制作即可（无需 @2x/@3x）
- **导入后 Unity 设置**：sprite sheet 需在 `.png.meta` 配置 `spriteMode: 2`(Multiple)、`spritePixelsToUnits`、`alignment`(下中对齐用 7)；单帧 sprite 用 `spriteMode: 1`(Single)
- **命名**：`类别_名称_序号.png`，如 `monster_tomato_00.png`、`weapon_spatula_icon.png`

## 优先级建议

| 优先级 | 资产 | 理由 |
|---|---|---|
| P0 | 主角行走 sheet、1-2 种敌人 sheet、1-2 种武器图标与投射物 | 核心循环可玩 |
| P1 | 调味料图标、更多敌人/武器、UI 通用素材 | 完整商店/背包体验 |
| P2 | 背景、特效、Boss、角色头像 | 视觉打磨 |

## 交付约定

- 美术交付 PNG 文件 + 对应的 `.meta`（若已在 Unity 中配置切片）
- sprite sheet 需保持**等间距横向排列**，帧数固定（与现有 4 帧风格一致或明确告知帧数）
- 若使用透明背景，确保 Alpha 通道干净，避免黑边
- 命名全部小写下划线分隔，避免中文与空格
