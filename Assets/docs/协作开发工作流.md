# 协作开发工作流

> 本仓库（`Cook-Em-All`）为主仓库。所有改动通过 **Pull Request (PR)** 合入 `main` 分支，不直接 push。

## 总体流程

```
main（稳定） ──┐
               │
            新建分支 ──> 提交改动 ──> 推送到 GitHub ──> 发起 PR ──> 评审 ──> 合并回 main
```

## 一、开始工作前

1. **同步本地 main**：每次开始新任务前，确保本地 `main` 是最新的
   ```bash
   git checkout main
   git pull origin main
   ```
2. **新建分支**：从 `main` 切出，分支名见下方命名约定
   ```bash
   git checkout -b feat/xxx      # 或 fix/xxx、docs/xxx
   ```

## 二、分支命名

采用 `类型/简短描述` 格式，全小写，单词用连字符分隔：

| 类型 | 用途 | 示例 |
|---|---|---|
| `feat/` | 新功能 | `feat/wave-system` |
| `fix/` | Bug 修复 | `fix/item-size` |
| `docs/` | 文档 | `docs/art-assets` |
| `refactor/` | 重构 | `refactor/backpack-grid` |
| `chore/` | 构建/配置/依赖 | `chore/upgrade-unity` |

## 三、提交规范

每个提交一个清晰的信息，格式：`类型(范围): 描述`

```
feat(backpack): 新增格子旋转功能
fix(monster): 修复番茄不移动的问题
docs: 更新美术资产清单
chore: 升级 Unity 到 2022.3.62
```

- 一个分支可以多个提交，但每个提交应是一个完整的逻辑单元
- 避免一个提交里塞入多个不相关改动

## 四、推送并发起 PR

1. **推送到 GitHub**：
   ```bash
   git push -u origin feat/xxx
   ```
2. **发起 PR**：在 GitHub 网页或用 `gh pr create` 发起，目标分支 `main`
3. **PR 标题**：同提交规范格式，如 `feat(backpack): 新增格子旋转功能`
4. **PR 描述**包含：
   - 改了什么、为什么改
   - 如何测试（如 Unity 编辑器运行某场景）
   - 截图/录屏（UI 改动建议附上）

## 五、评审与合并

- PR 至少经过仓库 owner 评审后方可合并
- 评审意见以 GitHub 评论形式提出，作者按反馈修改后继续推送同一分支（PR 自动更新）
- **合并策略**：默认使用 **Squash merge**（多个提交压缩为一个），保持 main 历史清晰
- 合并后**自动删除远程分支**

## 六、合并后清理

```bash
git checkout main
git pull origin main
git branch -d feat/xxx      # 删除本地分支
```

## 七、Fork 协作者（外部贡献者）

如果你没有主仓库写权限：

1. 在 GitHub 上 **Fork** 本仓库到自己账号
2. Clone 你的 fork：`git clone https://github.com/你的账号/Cook-Em-All.git`
3. 添加上游：`git remote add upstream https://github.com/yitian-chen/Cook-Em-All.git`
4. 工作流程同上，但推送到自己的 fork：`git push origin feat/xxx`
5. 在 GitHub 上发起 PR，从你的 fork 分支 → 主仓库 `main`
6. 定期同步上游：
   ```bash
   git checkout main
   git pull upstream main
   git push origin main
   ```

## 八、常用命令速查

```bash
# 同步主仓库
git checkout main && git pull origin main

# 新建并切换分支
git checkout -b feat/xxx

# 提交
git add . && git commit -m "feat(xxx): 描述"

# 推送新分支
git push -u origin feat/xxx

# 发起 PR（需要 gh CLI）
gh pr create --base main --head feat/xxx --title "feat(xxx): 描述"

# 合并后清理
git checkout main && git pull origin main && git branch -d feat/xxx
```
